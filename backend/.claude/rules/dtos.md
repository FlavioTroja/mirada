# DTOs — `src/stack/DTOs/<feature>/`

1. Group by entity/feature folder (`user/`, `person/`, `address/`, …).
2. Each file exports a Zod schema **and** the inferred type:
   ```ts
   export const UserCreateSchema = z.object({ … });
   export type  UserCreateDTO    = z.infer<typeof UserCreateSchema>;
   ```
3. > [!IMPORTANT]
   > **Always reuse `@prisma-gen/zod` (generated by `zod-prisma-types`) when a DTO mirrors a Prisma model.** Do not hand-write a Zod schema that duplicates a Prisma model — import the generated one and `.pick()` / `.omit()` / `.extend()` from it.
