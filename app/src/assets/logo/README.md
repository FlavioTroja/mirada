# Logo

These files are **placeholders** generated by `ng add @keijo/ui`. Replace them with the project's logo before going to production.

## Specs

| File | Size | Format | Notes |
|---|---|---|---|
| `logo.png` | ≤ 200 × 50 px | PNG, transparent background | Shown when the sidebar is **expanded** |
| `logo-collapsed.png` | ≤ 40 × 40 px | PNG, transparent background | Shown when the sidebar is **collapsed** |

## How they're wired

In `src/app/app.component.ts`, the `<keijo-sidebar>` element has:

```html
<keijo-sidebar
  [logoExpandedUrl]="'assets/logo/logo.png'"
  [logoCollapsedUrl]="'assets/logo/logo-collapsed.png'"
  …
/>
```

Replace the **files** here, not the paths in `app.component.ts`.
